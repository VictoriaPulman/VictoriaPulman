# Привет! Я начинающий Аналитик Данных 📊

Я нахожусь в процессе активного погружения в мир данных: учусь наводить в них порядок, искать логику, скрытые смыслы и превращать сухие цифры в понятные визуальные истории. 

Увлекаюсь оптимизацией рутинных процессов — например, для удобства работы автоматизировала процесс развёртывания и настройки виртуальных окружений в Python для своих учебных проектов.

---

### 🛠 Мой стек и инструменты:
* **Python:** Базовое программирование, понимание алгоритмической логики и структур данных.
* **Библиотеки данных:** `Pandas` (базовые манипуляции с данными, фильтрация, группировка), `Matplotlib` & `Seaborn` (построение и базовая кастомизация графиков).
* **SQL:** Проектирование простых запросов, логика объединения таблиц (`JOIN`), работа со вложенными запросами и понимание принципов оконных функций.
* **Excel & Google Sheets:** Анализ данных, построение дашбордов, работа со сводными таблицами и графиками.
* **BI-инструменты:** Поверхностное знакомство с экосистемой Power BI через Excel, горю желанием освоить полноценные BI-платформы на практике.
